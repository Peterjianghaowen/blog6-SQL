# Matching Parents and Children with SQL in Python

Tutorial code for estimating the intergenerational income elasticity (IGE)
from PSID data, using SQL (DuckDB) inside Python to build the parent-child match.

## Repository structure

```
code/            analysis scripts (run in numeric order)
data/raw/        raw PSID files (NOT included, see below)
data/processed/  DuckDB database created by the scripts (not tracked)
results/         tables (.csv) and figures (.png) generated by the code
run_all.sh       runs the whole pipeline
```

## Data (not redistributed)

Create a free account at https://psidonline.isr.umich.edu/ and download two files
into `data/raw/`:

1. **PSID Data Center** (https://simba.isr.umich.edu/): select these variables with
   "Variable List", choose *Microsoft Excel Spreadsheet* as output, and save as
   `J366679.xlsx` (your job number may differ; rename it to this name):
   `ER30000, ER30001, ER30002, ER32000, ER32006, ER78001, ER78002, ER81775,
   ER34901, ER34902, ER34903, ER34904, ER82001, ER82002, ER85629,
   ER35101, ER35102, ER35103, ER35104`
2. **Packaged Data > Main Study > Parent Identification: 2023**: unzip and keep
   `PID23.txt` (fixed-width, no header).

## How to reproduce

From the repository root:

```bash
pip3 install -r requirements.txt
./run_all.sh
```

Note: the Excel file must be read with the `calamine` engine
(`pip3 install python-calamine`); the default engine fails on PSID Excel exports.
Always run scripts from the repository root, because paths are relative.

## Pipeline

| Script | What it does |
|---|---|
| `code/load_data.py` | Reads the Excel file and the fixed-width parent ID file |
| `code/02_build_tables.py` | Renames variables; creates `individual_panel` and `parent_links` in DuckDB |
| `code/03_match_parents.py` | Joins children to mothers and fathers (`JOIN` on both ID parts, `UNION ALL`) |
| `code/04_aggregate_children.py` | `GROUP BY` child, `AVG()` over eligible parents; builds single-year and two-year income |
| `code/05_estimate_ige.py` | Log-log OLS with HC1 robust SE; writes `results/ige_main.csv` |
| `code/06_lifecycle_bias.py` | Repeats the estimates by child age group; writes `results/ige_by_age.csv` |
| `code/07_make_figures.py` | Draws the two figures in `results/` |

## Sample definition

- A person is identified by the 1968 interview number **and** the person number.
- Children are matched to biological parents via the 2023 Parent Identification File.
- Parent-child pairs living in the same family unit are dropped (family income would be identical).
- Children aged 25-55 in 2023 with positive incomes; the same sample is used for all regressions.
